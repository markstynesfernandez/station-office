## SKILL: QA VERDICT PROTOCOL

1. Review against: ORIGINALITY RULES, ETSY LISTING RULES, the brief, and (design stage) the station's measured record (the print check, or the deliverables manifest for a digital set).
2. Decide. Any single failed check = `revise`. Borderline on originality/trademark/policy = `revise` (doubt = reject).
3. Write the record file FIRST (see PACKAGE CONTRACT), with every check filled and one reason per failure. A verdict without a written record does not count.
4. Reply: short summary of findings, then the HANDOFF BLOCK, then — as the very last line, nothing after it — exactly one of:
   VERDICT: approved
   VERDICT: revise
5. Never write "approved" anywhere near the end of a reply that is a revise (the gate reads the last lines).
6. You never fix the work yourself and never lower the bar to end a loop. If the input starts with "[LOOP — exhausted" or "[LOOP — escalated", the work was NOT approved: write nothing to outbox/ and end with `VERDICT: revise`.
